# Actividad 1
Para poder ejecutar el servidor proxy, se debe runear desde una virtual box, linux.
Usando la terminal y el commando Python3 + el nombre del archivo.
Luego usando el firefox de la misma virtualbox, seteamos el proxy en la configuracion del navegador usando la IP "localhost" con puerto 8000


# Actividad 2
Para poder utilizar el DNS se debe runear de la misma forma usando una terminal con el mismo comando Python3 + el nombre del archivo.
Para probarlo se utiliza el comando "dig -p8000 @localhost" + la url de la pagina, por ejemplo "dig -p8000 @localhost example.com".
